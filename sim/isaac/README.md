# Isaac Sim asset (on hold)

Isaac Sim is kept for the future perception phase (large steps, depth camera, elevation map; see the
[control roadmap](../../docs/control_roadmap.md)). Current RL work runs in MuJoCo Warp ([warp_rl](../warp_rl/README.md)).
The first Isaac RL task (raw torques) failed — robot sat on its landing gear — and was removed; its code is kept at
the Git tag `isaac-raw-torque-2026-10-31` and its lessons in the [post-mortem](../../docs/terrain-run-2026-10-31.md).

What remains is the robot asset pipeline:

| file | what it does |
|---|---|
| `urdf/robo_bipedal.urdf` | generated by `../scripts/generate_urdf.py` (same meshes/masses as the MJCF) |
| `convert_urdf_to_usd.py` | URDF → USD with the Isaac Lab converter, then closes the loops |
| `add_loop_closures.py` | adds one loop joint per leg (linkYm ↔ shin at the wheel axle, excluded from the articulation tree) |
| `isaaclab_robo_cfg.py` | `ArticulationCfg` of the robot (DC-motor hips/wheels, gear servos, passive knees), reset pose at 0.27 m |
| `actuator_parameters.py` | reads `hardware/actuators.json` (torque limit, no-load speed, armature) |
| `preflight.py` | checks the assets (`--assets-only`) or the whole runtime (Isaac Sim 6.1, Lab v3.0.0-EA, CUDA) |
| `launch.py` | runs a script with the shared Isaac runtime (`runtime.local.json` or `ISAAC_PYTHON` / `ISAACLAB_PATH`) |
| `workspace.py` | cache and state paths beside the repository |
| `tests/test_assets.py` | URDF paths/inertias, reset pose vs MuJoCo, USD loop-joint authoring |
| `patches/` | local Isaac Lab CPU allocation patch |

```bash
cd PRIMUS
python3 sim/isaac/launch.py preflight.py --assets-only
~/test/isaac-rl/bin/python -m unittest discover -s sim/isaac/tests -v
python3 sim/isaac/launch.py convert_urdf_to_usd.py          # writes sim/isaac/usd/ (ignored by Git)
```

Versions: Isaac Sim 6.1.0.0, Isaac Lab **v3.0.0-EA** (commit `ae37b028ea415c91ea2bc32609efcd759ed2b974`), Python
3.12, RSL-RL 5.4.1. Do not mix with Lab 2.2 or Lab 3.0 stable / Sim 6.2. Isaac may ask you to accept the
[NVIDIA Omniverse license](https://docs.omniverse.nvidia.com/platform/latest/common/NVIDIA_Omniverse_License_Agreement.html);
only after accepting it, `OMNI_KIT_ACCEPT_EULA=YES` allows unattended runs.

**For the next Isaac task**, carry over the post-mortem lessons: hold the landing-gear servo target explicitly
(Isaac Lab starts position targets at zero = gear down), give the terrain a physics material (PhysX default
friction is 0.5; MuJoCo uses 1.0–1.2), make the tire an exact cylinder (custom geometry), terminate on body/gear
contact, and keep the model-based controller in the loop.
